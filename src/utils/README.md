# Shared Utilities

This package is reserved for reusable presentation helpers needed by the Day 5 CLI. Only the package initializer exists after Day 1.

```text
utils/
|-- README.md     # Planned shared presentation utilities
`-- __init__.py   # Makes utils a Python package
```

The planned `display.py` will format student records and other user-facing output. Dataset validation and data-structure algorithms belong in their own packages rather than in presentation utilities.
